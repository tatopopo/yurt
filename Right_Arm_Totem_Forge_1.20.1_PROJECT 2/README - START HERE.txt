RIGHT ARM TOTEM MOD
Minecraft Java 1.20.1
Forge 47.4.10

WHAT IT DOES
When a Totem of Undying actually saves you:
- your right arm disappears
- it stays gone after restarting Minecraft
- third-person right arm + sleeve are hidden
- first-person main hand is hidden too

IMPORTANT
The first-person event also hides the item you are holding in that hand.
This project still has to be BUILT into a .jar before CurseForge can use it.

EASIEST BUILD METHOD
Upload the CONTENTS of this folder to the ROOT of a GitHub repository.
Do not put this whole folder inside another folder.

Then:
1. Open the repository.
2. Click Actions.
3. Open "Build Forge Mod".
4. Run workflow if it did not start automatically.
5. When it turns green, open the run.
6. Download artifact: Right-Arm-Totem-Forge-1.20.1
7. Unzip it.
8. Put rightarmtotem-1.0.0.jar into the Mods folder for your CurseForge profile.

RESET THE ARM
Delete:
config/right-arm-totem-used.txt
from the CurseForge profile if you ever want the arm back.
